# Changelog

All notable changes to this theme. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Morganite: warm neutrals and a coral accent on a white page, in the Open Color variables Redmine 7 is built on.
- On screens 1100px and wider, the project menu moves into a dark left sidebar, in plain CSS; narrower screens keep Redmine's own layout.
- The issue list without zebra stripes, the issue as a quiet card, rounded fields and buttons, and a login card.
- A dark set for the system dark setting, in one block at the end of the stylesheet. Supported, but not recommended.
- Tested on Redmine 7.0.2 and the 7.0 line, in light and dark, at desktop and phone width: no console errors, no failed requests, no sideways scrolling, and text at AA contrast on the pages that matter.
